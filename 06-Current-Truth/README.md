# 06 Current Truth

This layer is the control tower for the playbook.

It should answer, quickly:

- What is currently confirmed?
- What is only observed/documented?
- What is still open?
- What are the highest-priority next tests?
- Where is the canonical evidence?

The current-truth layer must stay compact. It is not a second documentation library.
