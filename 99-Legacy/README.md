# 99 Legacy

This directory is a temporary migration boundary for the previous repository structure.

Content here is retained for historical reference while the playbook is rebuilt into the new architecture.

## Authority rule

Nothing in `99-Legacy/` is authoritative. Current truth lives in the new architecture once the migration is complete.

## Migration rule

For each legacy file:

1. identify unique knowledge;
2. assign one canonical owner in the new structure;
3. migrate the useful content;
4. remove duplicated material;
5. preserve historical evidence where it has value;
6. delete the legacy copy only after migration is verified.
