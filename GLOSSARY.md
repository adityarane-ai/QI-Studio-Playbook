# Glossary

## Agent
A bounded semantic reasoning component.

## Deep Agent
An agent pattern capable of decomposition, tool use, and optional subagent delegation.

## Decision Node
A deterministic workflow branching primitive.

## Rule
A deterministic condition used by workflow control.

## Compute
A deterministic arithmetic or transformation operation.

## Variable Update
A workflow state mutation.

## Subflow
A reusable workflow process.

## Artifact
A structured output or state object passed between stages.

## Approval
A human authorization gate.

## Human Input
A workflow step that collects human-provided information.

## Reflection
A bounded challenge/rework mechanism for reasoning results.

## Evidence
A source supporting a platform claim, experiment result, or runtime observation.
