# 03 Canonical Reference

This is the maintained explanation of established QI Studio behavior and recommended design patterns.

## Planned structure

### Nodes

`Nodes/` will contain one canonical page per node or tightly related node family.

### Tools

`Tools/` will contain one canonical page per tool or stable tool family after runtime verification is mature enough to justify one.

## Canonical page rules

Every page should distinguish:

- what is established;
- what is supported by documentation or UI observation;
- what is runtime confirmed;
- what remains open.

Canonical pages should explain the product, not reproduce entire evidence logs or long test transcripts.
