# 01 Governance

This layer defines how the QI Studio Playbook is maintained and interpreted.

It contains rules, evidence definitions, document ownership, naming conventions, and AI-reading guidance.

## Files

- `Evidence-Model.md` - evidence states and promotion rules
- `Documentation-Architecture.md` - what belongs in each repository layer
- `AI-Interpretation-Rules.md` - rules for using the playbook without inventing behavior
