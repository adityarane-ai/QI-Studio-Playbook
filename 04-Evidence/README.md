# 04 Evidence

This layer records proof.

## Evidence types

- `Runtime/` - controlled execution results, including passed tests and historical regressions.
- `UI/` - screenshots, observed configuration, and product-surface observations.
- `Tool-Contracts/` - supplied tool definitions and documented parameter/output contracts.

Evidence should be factual, timestamped where relevant, and linked to the canonical page it supports.

Do not turn evidence records into design manuals. Record the observation and its interpretation boundary.
